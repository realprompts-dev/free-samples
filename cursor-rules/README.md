# Cursor Rules: Free Sample

This folder contains one full rules file pulled from the Cursor Rules Pack:
`security-checklist.cursorrules`. It is reproduced verbatim, with a comment
header at the top citing the source pack.

## What is in the sample

A stack-agnostic security checklist designed to be dropped into
`.cursor/rules/security-checklist.cursorrules` or composed with
`@security-checklist` in Cursor chat. Covers input handling, injection,
auth, secrets, transport, output, rate limiting, dependencies, SSRF,
logging, and lightweight threat modeling.

The file works in Cursor 1.0+, Continue.dev, Aider, Windsurf, JetBrains AI,
or any tool that consumes per-project rules.

## What is in the full pack

14 rules files: seven language and framework files (TypeScript/Next.js,
Python/FastAPI, Go, Rust, MCP server in TypeScript, Tauri, React Native)
and seven cross-cutting files (testing patterns, security, performance,
code review, observability, monorepo conventions, refactoring, AI-friendly
comments). Each file is 50 to 150 lines of opinionated guidance.
