# realprompts: Free Samples

realprompts publishes opinionated, senior-dev-grade prompt and template packs
for engineers who use AI coding tools daily. Each product is built around a
real tool surface (Claude Code, Cursor, MCP) and assumes you are working in a
real codebase, not a tutorial. No filler, no marketing language, no boilerplate
you could have written yourself.

## What this repo contains

- `claude-code-prompts/`: five prompts (one per category) from the 50-prompt Claude Code Prompt Pack.
- `cursor-rules/`: the full `security-checklist.cursorrules` file from the 14-file Cursor Rules Pack.
- `mcp-starter/`: a minimal MCP server skeleton illustrating the pattern shipped in the 5-template MCP Server Starter Pack.

Each subfolder has its own README with details and a link back to the paid
product on Gumroad.
