# Claude Code Prompts: Free Sample

This folder contains five prompts pulled directly from the Claude Code Prompt
Pack. They are reproduced verbatim, with the same structure as the paid file:
title, use case, prompt body, and a single-line note on why the structure works.

## What is in the sample

`5-prompts.md` includes one prompt per category, picked for general utility:

- 1.1 Reproduce-first bug triage
- 2.1 Extract function with safety net
- 3.1 First-pass review of an unfamiliar PR
- 5.1 Strict TDD loop with Claude as the green light
- 7.1 Audit a route for OWASP top issues

## What is in the full pack

50 prompts across 8 categories: debugging, refactoring, code review,
documentation, testing, performance, security, architecture. Plus five
anti-patterns and a Claude Code keyboard cheat sheet. Includes a French
translation and a JSON build of the prompt set for snippet managers.
